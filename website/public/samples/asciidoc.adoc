== Introduction

One *tokenizer* for _browser_ highlights, `HTML`, and #ANSI# output.
See https://example.com/docs[the docs] and <<api,API>>.

NOTE: Tokens use exclusive `start`/`end` offsets.

WARNING: Unknown languages raise; they never guess.

TIP: Register custom languages without touching the tokenizer.

== Pipeline

. Tokenize with `highlight(source)`.
. Render with `renderHTML`.
. Theme with `--sh-*` variables.

[source,typescript]
----
const hl = await createHighlighter({ language: "typescript" });
const tokens = hl.highlight(source);
----
