# Languages

102 languages ship built-in and load lazily — only the languages you highlight are bundled and parsed.

## Popular languages

`javascript` (`js`), `typescript` (`ts`), `jsx`, `tsx`, `html`, `css`, `python`, `json`, `bash` (`sh`), `sql`, `yaml`, `markdown` (`md`), `java`, `go`, `rust` (`rs`), `php`, `ruby` (`rb`), `c`, `cpp`, `csharp` (`cs`), `swift`, `kotlin`, `toml`, `xml`, `dockerfile`, `diff`.

## Aliases

Common aliases and file extensions resolve automatically, case-insensitively: `js` → `javascript`, `ts` → `typescript`, `py` → `python`, `rb` → `ruby`, `rs` → `rust`, `cs` → `csharp`, `yml` → `yaml`, `md` → `markdown`, and `sh`, `shell`, `zsh`, `console`, and `shellscript` → `bash`. An unknown name throws `UnknownLanguageError`; `highlightAll` and `highlightCode` treat it as plain text instead.

## Custom languages

Anything missing can be registered at runtime — see [Getting started](/docs/getting-started).
