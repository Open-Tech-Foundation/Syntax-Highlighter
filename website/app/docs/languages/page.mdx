# Languages

101 languages ship built-in and load lazily — only the languages you highlight are bundled and parsed.

## Popular languages

`javascript` (`js`), `typescript` (`ts`), `jsx`, `html`, `css`, `python`, `json`, `bash` (`sh`), `sql`, `yaml`, `markdown` (`md`), `java`, `go`, `rust` (`rs`), `php`, `ruby` (`rb`), `c`, `cpp`, `csharp` (`cs`), `swift`, `kotlin`, `toml`, `xml`, `dockerfile`, `diff`.

## Aliases

Common aliases resolve automatically (`ts` → `typescript`, `py` → `python`, `rs` → `rust`, `sh` → `bash`, `md` → `markdown`, `github` → `github-dark` theme-style aliasing aside). Cyclic aliases are detected instead of looping forever.

## Custom languages

Anything missing can be registered at runtime — see [Getting started](/docs/getting-started).
