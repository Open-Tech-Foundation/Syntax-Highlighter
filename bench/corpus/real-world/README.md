# Real-world accuracy corpus

Unmodified third-party source files used to score highlighting accuracy against Shiki
(TextMate grammars), alongside the project-written showcase samples in `website/public/samples`.
One or two files per tier-1 language, pinned to a release tag or commit.

Each file remains under its original license and copyright, listed below; see the linked
repository for the full license text. These files are test fixtures only and are not
published with the package. Machine-readable provenance is in `sources.json`.
